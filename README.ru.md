# Mac Coffee 2.0

[English](README.md) · [Deutsch](README.de.md) · [Français](README.fr.md) · [简体中文](README.zh-Hans.md) · [日本語](README.ja.md) · [한국어](README.ko.md) · [Español](README.es.md)

Mac Coffee — лёгкое нативное приложение в строке меню macOS. Оно не даёт Mac автоматически уснуть, пока вы явно включили соответствующий режим.

## Возможности

- Режимы «Выкл.», «Не усыплять Mac» и «Не выключать экран».
- Сеансы на 30 минут, 1, 2, 4 или 8 часов либо без ограничения.
- Защита аккумулятора с порогом 10–30%, по умолчанию 15%.
- Запуск при входе через системный API `SMAppService`.
- Мгновенное переключение между восемью языками без перезапуска и сброса активного сеанса.
- Локализованные настройки, уведомления, ошибки, About, подтверждение выхода и VoiceOver-тексты.
- Единое подтверждение выхода для кнопки и `⌘Q`.
- Отдельные Direct и App Store сборки; Sparkle присутствует только в Direct.
- Нет прав администратора, helper, демона, аналитики, аккаунта или сервера.

Mac Coffee предотвращает только автоматический сон из-за бездействия. Ручной сон, закрытие крышки, выключение и защитные решения macOS продолжают действовать.

## Установка и использование

```sh
brew bundle
./scripts/build-local.sh direct
open "dist/local/Mac Coffee.app"
```

Откройте значок текущего режима в строке меню, выберите режим и длительность. В настройках можно изменить язык, порог батареи и запуск при входе. Режим «Выкл.» и выход из приложения немедленно освобождают системный запрос бодрствования.

Локальная сборка подписана ad-hoc и предназначена только для тестирования. Подписанные и notarized-версии будут опубликованы в [Releases](https://github.com/rekurt/Mac-Coffee/releases).

## Разработка и безопасность

Приложение использует публичные IOKit assertions, принадлежащие процессу. App Store-вариант работает в sandbox и не содержит Sparkle. Mac Coffee не собирает и не передаёт персональные данные.
